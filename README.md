# 하모니카 3D · 계이름 배우기

입술이 하모니카 취구에 닿는 곳을 여러 방향에서 관찰하고, 위치마다 날숨과 들숨을 구분해 보는 한국어 학습 웹앱입니다. 현재 단계는 **시각·조작 시제품**입니다. 실제 제품의 규격과 음 배열은 자료 확인 대기입니다.

## 실행

1. 압축을 풉니다.
2. `dist/harmonica-3d.html`을 WebGL을 지원하는 브라우저에서 엽니다. 스타일, 코드, 시제품 데이터가 포함되어 설치와 인터넷 연결 없이 실행할 수 있습니다.
3. 장면을 드래그하거나 방향 버튼을 선택합니다. 키보드는 장면에 포커스를 옮긴 뒤 방향키로 회전합니다. 투명도 100%에서는 얼굴 표면만 숨겨집니다.
4. 연주 위치와 호흡 방향을 선택합니다. 시제품 위치는 관찰용 문자로 구분합니다. 블루스 버튼은 다이아토닉 형상 시제품의 별칭입니다.

WebGL을 사용할 수 없는 환경에서는 연주 위치와 호흡 설명을 이용할 수 있습니다. 3D 그래픽 연결이 끊기면 복구를 감지하고, 실패 상태에서 다시 시도할 수 있습니다.

## 개발 및 시험

Node.js 22 이상과 Python 3가 필요합니다. 앱의 외부 런타임 패키지는 없습니다.

| 작업 | 명령 |
|---|---|
| 소스 실행 | `npm run dev` 실행 후 `http://127.0.0.1:4173/` 열기 |
| JavaScript 구문 점검 | `npm run check` |
| 자동 시험 | `npm test` |
| 단일 HTML 생성 | `npm run build` |
| 생성한 HTML의 내장 모듈·모델 확인 | `node tests/standalone_smoke.mjs` |

브라우저 회귀 시험은 별도로 Python Playwright와 Chromium을 갖춘 환경에서 실행합니다. 개발 서버를 켠 뒤 다음 명령을 사용합니다.

```sh
HA_APP_URL=http://127.0.0.1:4173 \
HA_STANDALONE="$PWD/dist/harmonica-3d.html" \
python3 tests/browser_qa.py
```

기본 결과 폴더는 `qa-output/`입니다. Chromium 실행 경로는 `HA_CHROMIUM`으로 지정할 수 있습니다.

배포 상태는 로컬 실행용입니다.
